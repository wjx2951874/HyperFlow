# HyperFlow V0.4.0 —— Miuix(Compose) 重构版构建说明

本目录是全新的 **Kotlin + Compose + Miuix** 工程（旧版纯 Java 手工构建链已停用）。
UI 全面采用 yukonga 的 Miuix 库（`top.yukonga.miuix.kmp:0.9.4`，HyperOS 原生质感），
玻璃采用同库 `miuix-blur`（RuntimeShader，minSdk 33，三台 OS4 设备均满足）。

## 目录结构
```
hyperflow-miuix/
├── settings.gradle.kts / build.gradle.kts / gradle.properties
├── app/
│   ├── build.gradle.kts          # compileSdk 35 / minSdk 33 / versionCode 35
│   ├── libs/libxposed-api.jar    # 本地 libxposed API（坐标源不稳定，内置）
│   └── src/main/
│       ├── kotlin/com/hyperflowplus/   # Miuix UI（Compose）
│       │   ├── MainActivity.kt         # 入口：主题/三页签/玻璃backdrop
│       │   ├── HFState.kt              # 全局状态 + su 数据加载 + 秒开缓存
│       │   └── ui/{Home,Messages,Conversation,Settings}Screen.kt
│       ├── java/com/hyperflowplus/     # Xposed hooks（保留 Java，逻辑不变）
│       │   ├── XposedEntry.java / Config.java / RootExec.java / MiflowLog.java
│       │   └── hooks/*.java            # 亮屏流转/分身/短信持久化/来电/自动解锁
│       ├── resources/META-INF/xposed/  # LSPosed 元数据
│       └── AndroidManifest.xml
├── ksu-module/                  # 刷机模块：service.sh + module.prop
└── .github/workflows/build.yml  # GitHub Actions 云构建
```

## 构建方式（二选一）

### A. GitHub Actions 云构建（推荐，无需本地环境）
1. 把本目录推到你账号的仓库（`wjx2951874/HyperFlow`，分支 master）：
   ```
   cd hyperflow-miuix
   git init && git add -A && git commit -m "Miuix UI v0.4.0"
   git remote add origin https://github.com/wjx2951874/HyperFlow.git
   git push origin master
   ```
2. 仓库 Settings → Secrets and variables → Actions → 添加 3 个 secret（**可选**，不配则用 debug 签名）：
   - `HF_KEYSTORE_B64` = 你本地 `base64 -w0 keystore.jks` 的输出
   - `HF_KEY_ALIAS` = hyperflowplus
   - `HF_KEY_PASS` = hyperflowplus
3. Actions → Build HyperFlow → Run workflow（或推送 v0.4.0 tag 自动构建+发 Release）
4. 产物：`HyperFlow-0.4.0-flashable.zip`（Actions Artifacts 或 Release 页）

### B. 本地构建（有 Android Studio / SDK 时）
```
cd hyperflow-miuix
gradle assembleRelease
```
输出 `app/build/outputs/apk/release/app-release.apk`，按 workflow 的 assemble 步骤手动组 zip。

## 首次构建可能报错项（按序处理）
1. Compose/Miuix API 签名差异 → 按报错行改对应 .kt
2. `HF_KEYSTORE_B64` 未配 → 自动回退 debug 签名，能出 zip
3. Miuix 组件名变化 → 对照 https://compose-miuix-ui.github.io/miuix/components/index

## 发布链
- 打 tag `v0.4.0` 推送 → Actions 自动 Release（含 flashable.zip）
- update.json 需同步更新 versionCode=35 / zipUrl=Release 资产直链
- 酷安发布帖：模块 zip（刷入自动装 App）+ GitHub 链接
