# HyperFlow 构建说明（当前 v0.5.3）

本工程为 **Kotlin + Compose + Miuix** 工程（Java hooks 保留，见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)）。
UI 采用 Miuix 库（`top.yukonga.miuix.kmp`，HyperOS 原生质感），玻璃/悬浮采用同库 blur + InstallerX 同源结构。

## 目录结构

```
hyperflow-miuix/
├── settings.gradle.kts / build.gradle.kts / gradle.properties
├── app/
│   ├── build.gradle.kts          # compileSdk 35 / minSdk 33 / versionCode 83（发布 bump 处之一）
│   ├── libxposed-stub/           # libxposed API 本地桩（坐标源不稳定，内置）
│   └── src/main/
│       ├── kotlin/com/hyperflowplus/   # Miuix UI（Compose）
│       │   ├── MainActivity.kt         # 入口：Scaffold + 4 Tab + 弹窗智能移位 + 更新检测
│       │   ├── HFState.kt              # 全局状态 + su 数据加载 + 环境检测缓存
│       │   └── ui/                     # 首页/流转/消息/会话/设置/引导/主题/弹窗/许可
│       ├── java/com/hyperflowplus/     # Xposed hooks（Java，逻辑稳定）
│       │   ├── XposedEntry.java        # libxposed 入口（进程分发 + hook 装配）
│       │   ├── Config.java / RootExec.java / MiflowLog.java

├── .github/workflows/build.yml  # GitHub Actions 云构建（CI）
└── update.json                  # 在线更新元数据（仓库根）
```

## 构建方式

### A. 本地构建

```bash
cd hyperflow-miuix
gradle :app:assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

Release APK 需要签名。签名密钥为私有信息（不写入本仓库与本文档）；CI 侧通过
GitHub Actions secrets 注入（密钥名见 `.github/workflows/build.yml`，密码值不入库）。

### B. GitHub Actions 云构建

推送到仓库 main 分支（或打 `v0.5.x` tag）触发 workflow，产物为可刷入 zip + APK（Artifacts / Release 页）。

## 组装可刷入 zip（8 条目）

```
HyperFlow-x.y.z-flashable.zip
├── module.prop          # id=hyperflow / version / updateJson（KSU 识别）
├── HyperFlowPlus.apk    # 管理 App（根目录，service.sh 用它装/升级）
├── service.sh           # 开机：KSU 白名单 + 自动安装/升级 App
├── README.txt           # 模块内说明
└── system/
    └── priv-app/
        └── HyperFlowPlus/
            └── HyperFlowPlus.apk   # 系统应用位（刷入自动装）
```

参考脚本：`scripts-build-v0443.sh`（python zipfile 组装先例，改版本号复用）。

## 发布检查清单（发版必做）

1. **bump 4 处版本号**：`app/build.gradle.kts`（versionCode/versionName）、
   `ksu-module/module.prop`（version/versionCode）、仓库根 `update.json`（version/versionCode/zipUrl/changelog）、
   GitHub Release（tag + zip 资产）
2. **update.json 合法性**：python `json.dumps(ensure_ascii=False, indent=2)` 生成后 `json.loads` 校验
   （手写 JSON 出错会让 KSU/App 都解析失败——历史根因）
3. **组装 zip**：8 条目（见上），APK 放根 + priv-app 两份
4. **验证三通道**：gh-proxy.com / jsDelivr / raw 加时间戳强刷，确认返回最新版本号
5. **提交范围**：只 `git add` 变更文件（**不要 `git add -A`**，会卷进产物目录）
6. **私密文件**：`docs-internal/`、密钥、密码等绝不提交（已在 .gitignore）

## 首次构建可能报错项

1. Compose/Miuix API 签名差异 → 按报错行改对应 .kt
2. libxposed 坐标源不稳定 → 用 `libxposed-stub/` 本地桩
3. Miuix 组件名变化 → 对照 https://compose-miuix-ui.github.io/miuix/components/index
