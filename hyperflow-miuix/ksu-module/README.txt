HyperFlow V1.1.0 · 作者 酷安@翰德姆
澎湃OS 互联通知流转增强（KernelSU / APatch / Magisk 模块）

【功能】
- 解锁时流转：解锁状态下强制放行通知流转到另一台设备
- 分身流转：999 空间微信/QQ 通知独立流转，标题带可自定的【双开】前缀
- 点击只开分身：在另一台设备点分身通知，只拉起分身，不会连带把主应用拽起来
- 妙享直通免密：锁屏凭证自动捕获 + 授权盘自动填充，验证通过自动关闭授权界面
- 来电流转：来电以 VoIP 形态流转到另一台设备（锁屏 / 亮屏均可）
- 短信归档：流转短信存入 App 消息页，支持排序 / 搜索 / 删除；可选写入系统收件箱（默认关）
- Miuix 管理 App：环境检测 / 消息页 / 主题（悬浮导航栏 + 液态玻璃）/ 在线更新

【作用域】（在 Xposed 管理器里勾选）
com.milink.service       小米互联服务（通知流转 / 来电 / 短信，核心）
com.xiaomi.trustservice  妙享直通授权盘（远控免密）
com.xiaomi.mirror        分身通知源头（点击只开分身）
com.android.incallui     电话界面（亮屏来电流转）
android / system         系统框架（锁屏凭证捕获）
                         注：这两个是同一件事的两种框架标识，按你装的框架勾选，
                             不确定就两个都勾。

【刷入】
1. KernelSU / APatch / Magisk 管理器 → 安装本 zip → 重启
   （App 会被预置为系统应用）
2. Xposed 管理器启用 HyperFlow 模块，勾上上面 6 项作用域
3. Root 授权：service.sh 会自动把 com.milink.service 与 com.hyperflowplus 写入白名单

【在线更新】
- 管理器模块列表点检查更新，或 App 内「设置 → 版本与更新」
- 默认走稳定通道；Beta 通道需在设置页连点版本行解锁

【注意】
- 写入系统收件箱属可选功能，默认关闭；开启后若出现重复显示或异常，关闭即可
- 详细文档见仓库 docs/（面向用户的更新日志）与 docs/dev/（技术实现资料）
