# HyperFlow App 图标设计 Brief（beta46，纯图候选）

- 交付环境：mobile_direct（Mobile）
- 用途：①App 桌面启动图标（替换现有 ic_launcher，1:1）；②模块图标（LSPosed/KSU 列表小图标，小尺寸可识别）
- 主题：HyperFlow 澎湃 OS 互联增强模块——多设备互联 + 多功能（来电/短信/通知流转、妙享直通/密码自动填、应用双开、镜像回复、App 内消息）
- 商品：无实体商品；核心对象 = HyperFlow 品牌标识
- 风格约束：保持蓝白流转主题微调——HyperOS/MIUI 蓝（#0BBFF8 系）+ 白色图形；HyperOS 圆角方形图标容器；扁平简洁、轻微质感；**图形语义从"流转双箭头"扩展为"互联+多功能"**（可保留箭头基因，但体现多通道/多设备/中心枢纽）
- 画幅：1:1 方图（App 图标标准）
- 无文字（App 图标惯例，系统自动显示 App 名；如需字标版另行生成）
- 禁止：拟物 3D、复杂场景、水印、随机字符、多隐喻堆叠、发丝级细节
- 候选方向（身份来源+形态结构两维不同）：
  1. 互联枢纽：中心圆点向四周发射连接线+触点，保留双箭头基因
  2. 轨道环绕：中心双箭头环 + 外侧环绕轨道带节点（流转+持续互联）
  3. H 融合：HyperFlow 首字母 H 抽象为"双通道+连接点"（品牌字母+互联）
