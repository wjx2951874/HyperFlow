## 历史已放弃的方案（别再走回头路）

| 方案 | 放弃原因 |
|---|---|
| 分身"user 归一"（999→0） | 发送端 systemui 也显示一条一样的 → 重复 bug |
| 分身"镜像通知"（system_server 再造 user0 镜像） | 复杂度高、需额外作用域，且用户确认不需要 |
| 短信写系统收件箱默认开 | 错误显示/重复互联/多次复现 → 改默认关 + 倒计时确认 |
| 弹窗用系统 Dialog | 悬浮窗场景闪退（用户实测）→ 全量换 Popup |
| 悬浮时玻璃降级 Blur（v0.5.2 临时方案） | 玻璃效果失效 → v0.5.3 换 InstallerX 原版结构根治 |
| LSP 检测要求"配置态 && 运行态"双通过 | milink 非 root 进程写不了时间戳 → 永远爆红 → 改配置态即绿 |
| 更新通道用 jsDelivr | 对 update.json 有 12h+ 陈旧缓存且 ?v= 无效 → 弃用，改 ghproxy 镜像 |
