# HyperFlow 更新日志

## v1.1.0（versionCode 201）— 2026-11-01

- **点击分身通知不再连带拉起主应用**：在通知流转源头接管用户判定，分身通知按 999 用户查找任务；此前会以主空间用户（0）查到主微信窗口并搬上屏，造成同屏双开
- **短信列表排序修正**：排序改用不会溢出的长整数比较（原实现把两个毫秒时间戳相减后转 `Int`，相差超过约 24.86 天即翻负号、比较结果反转）；时间解析补齐旧归档格式与秒/毫秒时间戳并加合理性闸门，`content_time` 无效时回退同一行的时间戳列；去重在时间不可信时按正文匹配
- **锁屏凭证捕获**：修正主线通道的类名路径，配合妙享直通自动填充，授权盘基本免手动输入
- **来电流转**：亮屏状态下的来电补齐通知广播（此前仅锁屏来电会流转）
- **作用域补齐**：新增 `com.xiaomi.trustservice`、`com.xiaomi.mirror`、`com.android.incallui`，并同时支持新版框架的「系统框架」双标识（`android` / `system`）
- **一键启用修复**：引导页 / 首页 / 设置页共用的作用域勾选脚本此前只写入 4 项，漏掉上面的 `com.xiaomi.mirror` 与 `com.android.incallui`，现按统一列表一次写入 6 项
- **仓库清理**：移除历史测试包（13 个 beta APK 与旧刷机包），逆向分析类技术资料移入 `docs/dev/`
- **Beta 通道**：入口保留，但在设置页需连点 10 次解锁，正式版默认只走稳定通道

## v1.0.0（versionCode 126）— 2026-10-04

- **正式版发布**：HyperFlow 1.0.0
- **引导页**：功能说明更新（解锁时流转 / 分身流转 / 短信持久化）+ 新增法律与责任声明
- **搜索**：重构为 KernelSU 同款全屏搜索（常驻栏 → 全屏搜索页，会话/信息分组，命中高亮，点击直进会话）
- **短信本地删除持久生效**：删除指纹口径统一，实时轮询写回时过滤已删除项
- **模块描述**：KSU 与 LSPosed 显示统一
