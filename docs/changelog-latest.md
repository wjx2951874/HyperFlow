# v0.5.15

1. 环境检测彻底重写：去掉 /data/adb 全盘遍历与配置文件（modules.list/scope/DB）解析，改为「框架 daemon 存活 + 运行时注入探针」双证据判定；本模块不再要求勾选本 App（小米互联服务 + Android 系统框架即为推荐作用域），重启一次即生效，免疫「关闭框架/禁用模块后目录残留」导致的误报。
2. 首页：移除顶部「环境已就绪 N/6」汇总行；「重新检测」收进环境检测详情弹窗右上角（小字按钮，连点 3 次可打开「环境正常为何无法使用？」隐藏入口，含软重启与复制检测日志）。
3. 设置页：新增「软重启框架」一键按钮（无需整机重启）；「重新引导」独立入口移入调试区（原版本连点 3 次机关移除）；版本行保留「点击可检查更新」。
4. 设备信息卡改为 KernelSU 管理器同款（图标 24dp + 标题加粗 + 内容灰字，无分割线）；调试机关改连点「系统」行 5 次捕获日志。
5. 引导页：弹窗上移（限高 0.62 屏高、底部间距加大）、标题调小、等待时间 10 秒 → 5 秒。
6. 消息页：搜索框再压一档高度；会话层支持长按多选（已选 N 个会话 + 批量删除 + 取消，学小米短信 ActionMode）。
7. 会话详情：多选时「复制」仅在选中 1 条时显示；选「最早在前」时打开会话自动定位到最新消息（导航栏避让区上方）。
