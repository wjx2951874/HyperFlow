# HyperFlow 1.1.0 更新日志

**正式版发布**（versionCode 201）—— 本文覆盖 beta61 ~ beta72 全部改进。

---

## 主题

- 重做了主题设置与界面（由酷安 [@Lxithral](https://www.coolapk.com/u/29830069) 提议 / 协助）

---

## 功能

1. **解锁时的来电流转**：现已做到与锁屏时一致的效果 —— 支持 VoIP 的设备可直接接听，不支持的设备自动降级为卡片通知（由酷安 [@巛秀儿](https://www.coolapk.com/u/1307807) 提议 / 协助）

2. **双开通知流转修复**：修复用其他设备拉取分身通知时，会同时拉起两个微信、且主微信覆盖在上层的问题（实测仍存在个别场景会拉起主微信）（由酷安 [@柴宝柴宝](https://www.coolapk.com/u/2829150) 提议 / 协助）

3. **双开通知前缀可自定义**：流转通知的标题前缀支持自由编辑

4. **新增妙享直通**：首次在授权盘输入一次密码（或在 App 内预设置），此后即便重启，其他设备也可直接连接，无需再手动授权（Hook 小米信任服务组件）

5. **修复短信列表排序与日期错乱**：本地归档与实时消息同时显示时顺序混乱、日期显示不准
