# v0.6.16.1

1. **解锁二次流转去重**：锁屏流转后解锁瞬间，milink 会对同一条通知重新评估（屏幕状态刷新），
   之前 hook 无条件放行导致短信/来电被流转两次。现在加 **30 秒内容指纹去重窗口**——
   已强制流转过的通知再次评估时交还原生判定（亮屏原生拒绝 → 不再流转）；新通知不受影响，
   亮屏来电照常流转。
2. **作用域检测回退合一判定**：全部勾选作用域仍提示"未勾选全"的问题修复——判定回到
   libxposed service 快照（v0.6.8 合一版行为）：勾选全部 → 绿；取消全部 → 重新检测刷新
   变黄；模块被禁用 → service 断开 → 红。重新检测用 shell 实时读 scope 文件刷新快照
   （支持"全取消=空集"，不再误报就绪）。
3. **重新检测 Toast 修复**：点击"重新检测"弹系统底部 Toast（applicationContext 系统窗口，
   弹窗上层也能显示）——提示"强行停止本 App 再次进入，可获得更准确的检测结果"。
