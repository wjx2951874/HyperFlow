v0.5.8
1. 修复 KernelSU 管理器模块页在线更新不显示日志：KSU 会把 update.json 的 changelog 字段当 URL 请求，此前该字段是普通文本导致解析失败、只显示"开始下载"。现改为指向本文件的链接，KSU 与 App 内检测均可正常展示更新日志。
2. 修复"去 KSU 检测"打不开：跳转包名列表补齐官方 KernelSU 管理器包名（me.weishu.kernelsu），并加 pm path 校验与 monkey 兜底。
3. 修复 LSP 运行态误判：模块被非 root 进程（如小米互联服务）加载时写不进入 /data/adb 时间戳，重启生效后仍提示"请重启设备"；检测新增 /proc 内存映射探测，加载过的进程可直接识别为已生效。
4. 修复底部导航栏遮挡内容：悬浮导航栏不占布局导致列表底部被胶囊遮住，内容区补底部留白，内容可滚动上浮。
5. 修复浅色模式下液态玻璃黑底残留。
6. 会话详情排序按钮改为与消息页一致的选择弹窗（发送人/时间/倒序）。
7. 修复本地存档与小米端实时消息重复显示：同一内容（时间差≤2分钟）仅保留小米端；小米端缺失时才显示本地记录并标注（本地）。
8. 消息列表与会话详情支持长按多选、复制、删除（删除含确认提示）。
9. 消息页面新增搜索框，按发送人与正文实时过滤。
10. 环境就绪状态图标改用谷歌官方 Material 图标：通过 = 实心圆对勾（CheckCircle），未通过 = 红色圆环叹号（ErrorOutline），替换此前手写 path 的空心圆环勾。
