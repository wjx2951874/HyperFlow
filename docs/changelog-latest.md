v0.5.10
1. 悬浮胶囊移入内容容器内部（backdrop 采样节点子树）：修复液态玻璃黑底根因——LayerBackdrop 的坐标换算要求模糊节点是 backdrop 节点的后代，此前胶囊为兄弟节点导致采样落空；移入后玻璃真实折射页面内容，采样异常时半透明容器色兜底，永不黑。
2. 内容区去除底部留白：学 KernelSU/安装工具做法，内容铺满到底，悬浮胶囊 overlay 覆盖其上（被胶囊盖住的部分可看不到，周围内容正常显示）。
3. 环境检测大修：LSP 框架"活跃"判定升级为 目录存在 + daemon(lspd) 进程存活；关闭框架时立即检出异常并引导一键启用，不再误报"环境正常"；移除"已启用但未生效"黄条，配置命中即绿，重启一次刷完就生效。
4. 消息页新增设置项"仅显示实时消息"：开启后本地存档隐藏（不删除），仅显示小米端实时获取的消息；默认本地+实时一起显示。
5. 搜索框对齐小米短信 MIUI 搜索栏参数：圆角 22dp、背景 surface_container_low、内容边距 12dp。
6. 会话详情多选删除按钮改为 MIUI ActionMode 样式（垃圾桶图标 + 文字），对齐系统短信操作栏。
