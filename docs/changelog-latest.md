# v1.0.0（正式版）

1. **正式版发布**：HyperFlow 1.0.0 正式版（版本号体系延续，versionCode 126）
2. **引导页文案更新**：功能说明对齐当前能力（亮屏流转 / 分身流转 / 短信持久化，含限制标注）；
   新增「法律与责任声明」：禁止商用与再分发、后果自行承担、知识产权声明、数据不上传、禁止非法用途等
3. **更新日志排序修复**：最新版本置顶，旧版本向下排
4. 搜索全量重构（KernelSU 同款全屏搜索：常驻栏 + 分组 + 命中高亮 + 点击直进会话）

# v0.6.16.9

1. **修复搜索结果点击无效**：点击搜索结果时先收起搜索页再打开会话详情
   （此前会话在搜索覆盖层下方打开被遮住，需退出搜索才可见）。

# v0.6.16.8

1. **修复搜索无结果**：展开动画完成回调缺失导致状态卡在展开中，结果区永不显示。
   恢复 KSU 原版 `finishedListener`：动画结束即进入已展开状态，输入后立即展示
   「会话 / 信息」分组搜索结果与命中高亮；
   同时展开瞬间预填完整会话列表（KSU 展开态默认全量）。

# v0.6.16.7

1. **修复搜索栏点击无反应**：常驻搜索栏的点击事件被 Miuix 输入框内部消费拦截，
   改为 KSU 原版的 `detectTapGestures` 手势监听方式，点击即进入全屏搜索页。

# v0.6.16.6

1. **搜索重构为 KernelSU 同款全屏搜索**：
   - 消息页顶部常驻搜索栏（胶囊样式，搜索图标 + 「搜索消息」），点击进入全屏搜索页；
   - 全屏搜索页：键盘自动弹出、右侧「取消」按钮（系统返回键同样收起）、输入后一键清空；
   - 结果按「会话 / 信息」分组（KSU 分组头样式），点击结果直接进入对应会话；
   - 命中标注：发送人命中 → 会话行左侧主色竖条高亮（仅正文命中为浅色条）；
     消息正文命中的关键词段主色加粗高亮。
2. **本地删除持久生效（延续验证）**：删除指纹口径统一（正文统一过 `[N条]` 聚合标记清洗），
   实时轮询写回本地时过滤已删除指纹 —— 本地删除后不再复活、不再残留。
