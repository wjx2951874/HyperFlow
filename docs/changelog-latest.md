# v0.6.16.2

1. **锁屏来电流转去冗余卡片**：来电 voip 走 milink 广播链路（不经通知评估），
   锁屏时正常流转全屏来电；但"来电通知卡片"也会被一并流转 → 接收端多出一张
   冗余卡片。本版来电卡片不再放行（返回 FALSE），锁屏来电流转只剩 voip 全屏，
   无多余卡片。注意：接收端为 OS3/苹果等不支持 voip 的设备时，来电原本靠这张
   降级卡片接听——本版后此类设备收不到来电（与当前实测环境一致：接收端可 voip）。
2. **亮屏来电标注已知限制**：milink 原生设计在亮屏时不发送 voip 广播（防误接），
   模块无法在 Java hook 层打开该链路（模拟锁屏/全局劫持均误伤正常通话，已废弃）。
   亮屏来电不可流转属原生限制，待后期研究。
3. **二级页顶栏对齐**："日志列表"/"开放源代码许可"自带顶栏不再被 Scaffold 空槽
   高度推低，标题与箭头统一顶到状态栏下方标准位置（与主界面标题同位置，
   箭头为消息会话页同款 MIUI 返回箭头）。
4. **搜索占位字号**："搜索消息"占位字号 13sp → 14sp（小米短信搜索栏 hint 同款
   Miuix label 默认字号）。
